# StyledMD

A QuickLook plugin (`QuickLook.Plugin.StyledMD`) that override how QuickLook renders `.md` files.

The opinionated style is inspired by amazing design of the website of Typesafe.ai. It's far from there but the plugin tries to mimic the vibe of strong contrast of font weight and size, higher base font weights and and soft color palette.

## Requirements

| Item | Needs |
|---|---|
| OS | Windows |
| QuickLook | A version whose Markdown viewer has `MarkdownPanel._resources` (Built with QuickLook 4.5.0) |
| Bebas Nenu (Font) | For intended h1/h2 styling |
| Roboto or Noto Sans (Font) | For intended general font styling |

## Install

QuickLook plugins can be installed by previewing the `.qlplugin` files.

## Privacy and safety

- The plugin makes no network requests.
- It changes only QuickLook's in-memory copy of the viewer's template and style sheets. It does not edit any QuickLook file.
